# ADR-0005 — User Journey State Machine
Status: Accepted
Date: 2026-08-24

## Context
The platform needs relationship continuity without judging spirituality.
## Decision
Use canonical platform relationship states separate from theological/spiritual judgment. No hidden maturity score; Companion and Disciple-Maker transitions require human validation.
## Alternatives Considered
Numeric maturity scoring and analytics-only advancement were rejected.
## Consequences
Session engagement state remains separate from canonical relationship state.
## Implementation Notes
See `journey-states.yaml` and `USER_STATE_MACHINE.md`.
