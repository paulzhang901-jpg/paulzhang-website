# ADR-0008 — Version Boundaries
Status: Accepted
Date: 2026-08-24

## Context
The long-term vision exceeds a responsible first release.
## Decision
Strictly distinguish V1 public foundation, V1.5 identity/personalization/structured formation, and V2 community/mentoring/multiplication.
## Alternatives Considered
Building the full platform in V1 and organizing solely by technical ease were rejected.
## Consequences
Every task and route declares release scope; later scope cannot enter V1 by convenience.

See `RELEASE_BOUNDARIES.md`.
