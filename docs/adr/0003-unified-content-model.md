# ADR-0003 — Unified Content Model
Status: Accepted
Date: 2026-08-24

## Context
Content will appear across many discovery and formation surfaces.
## Decision
Use one canonical content object with references from many presentation contexts; avoid duplication.
## Alternatives Considered
Per-surface copies and route-owned content were rejected.
## Consequences
Canonical IDs, provenance, translation state, and publication filtering are required.
## Implementation Notes
The bootstrap defines a conceptual/schema contract, not a database.

None.
