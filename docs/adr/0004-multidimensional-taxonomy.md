# ADR-0004 — Multidimensional Taxonomy
Status: Accepted
Date: 2026-08-24

## Context
Format, subject, need, formation stage, and audience answer different questions.
## Decision
Maintain separate content type, topic, life need, journey stage, and audience dimensions.
## Alternatives Considered
One generic category/tag tree was rejected.
## Consequences
Registries and content validation must preserve dimension boundaries.
## Implementation Notes
Canonical values live in `config/architecture/taxonomy.yaml`.
