# Version Scope

## V1 — public front door, content, relationship entry

Home, Start Here, Library, Stories, companionship entry, Growth landing, Community landing, About, GCCM landing, Search, contact/prayer/support/legal; plus unified content, taxonomy, bilingual readiness, SEO, event architecture, gentle encouragement, subscription entry, and privacy baseline.

## V1.5 — identity, personalization, structured formation

Authentication, profiles, saved content, My Journey, growth profile, pathway enrollment/progress, private reflections, personalized next steps, basic AI Navigator, and basic mentor linkage.

## V2 — community, mentoring, leadership, multiplication

Groups, cohorts, discussions, mentor workflows/matching/dashboard, Rule of Life tracking, formation assessments, AI Mentor Assistant, disciple-making workflows, Serve → Lead → Multiply, GCCM integration, leadership development, and multiplication metrics.

Future scope **must not** be pulled into V1 merely because implementation would be technically convenient. See [Release Boundaries](../architecture/RELEASE_BOUNDARIES.md) and [ADR-0008](../adr/0008-version-boundaries.md).
