# User Journey

Experience journey:

Discover → Explore → Stay → Trust → Connect → Walk Together → Grow → Belong → Serve → Lead → Multiply

Platform relationship mapping:

| Experience | Platform relationship state |
|---|---|
| Discover | Visitor |
| Explore / Stay | Reader |
| Trust | Returning Reader |
| Connect | Connected Person |
| Walk Together / Grow | Growth Seeker |
| Belong / Serve | Participant |
| Lead | Companion |
| Multiply | Disciple-Maker |

These are platform relationship states, not algorithmic judgments of spiritual maturity, holiness, salvation, faithfulness, or worth. No hidden numeric spiritual-maturity score is permitted. Later human-accountability transitions require human validation; see [User State Machine](../architecture/USER_STATE_MACHINE.md) and [ADR-0005](../adr/0005-user-journey-state-machine.md).
